# Program recommendation entry — approved direction

Audience: HR, leaders and organization sponsors. Goal: understand the service and
start the existing organization-needs checklist. User approved a dedicated public
landing page and a hero entry. Keep five distinct paths: recommendation, team/org
diagnosis, individual Self Diagnostic, catalog, inquiry. No path is retired.

## Direction contract

THESIS: Explain what the recommendation delivers before asking for organization
context. Avoid presenting a generic diagnostic as the only way into BinaHub.
OWN-WORLD: Extend the existing BinaHub public site: Jakarta, navy, white, cool pale
surfaces, restrained gold. Existing hero art stays. New landing uses typography,
report rows and a compact numbered process; no new imagery or fabricated proof.
STORY: See the purpose, inspect an explicitly illustrative report outline, understand
the steps, then open the existing five-stage form. Other paths stay discoverable.
FIRST VIEWPORT: Left-aligned heading and primary start action; a compact report
outline on the right. At phone width text and action come before the outline.
FORM: Code-led extension of the exact structure approved in chat; no concept roll
because the user already selected purpose, hierarchy and content. No new world.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Boundaries

Do not change CEO questions, scoring, pricing, consent, payment activation or data
retention. Website catalog edits already in the working tree are unrelated and
must not be staged. Free reports get immediate practical guidance, not a one-month
return promise. Paid longitudinal features and reliable paid delivery remain gated
until separately implemented and verified; this work cannot claim they are live.

## Confirmed hero revision

The user chose a two-message homepage hero after the landing was built. Keep
the incumbent background, orbit art, colors and typography. First message:
organization program recommendations leading to the new landing. Second:
BinaHub's existing growth message leading to the diagnosis choice entry.
Only title, description and CTAs rotate, every eight seconds after introduction.
Manual labeled selectors and pause/play stay available. Pause on hover, touch,
keyboard focus, offscreen/hidden page; stop auto-rotation after manual selection.
Reduced-motion users get manual navigation without automatic rotation. Preserve
panel height by overlapping grid panels; inactive links cannot receive focus.
